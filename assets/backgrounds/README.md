# Background images

Every image must be the owner's own, public domain, or CC0. Record each one here before
committing it. Ship images sized for the panel (about 1920 px wide, WebP or AVIF).

The clock cycles through the files listed in `index.json` (same order as below). To add an
image, put the file here, add an entry to `index.json`, and add a row to this table.

Images from The Metropolitan Museum of Art are from its Open Access program: public-domain
works released under CC0, free for any use. Each was cropped to 16:10 and resized to at most
1920 x 1200. Works showing human or animal figures and works carrying Quranic text were left
out on purpose.
