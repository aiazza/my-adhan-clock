# Adhan audio

Optional. Put `adhan.mp3` (and `adhan-fajr.mp3` for Fajr) here to make them the default sound
for every tablet that loads this site. A recording chosen in the settings panel on a tablet takes
precedence; with neither, the clock plays a soft synthesized chime.

Only add recordings you have the right to redistribute, and note the reciter and source here.

"as-salatu khayrun min an-nawm"). Tags and cover art were stripped; the audio is unchanged
(128 kb/s, 2 min 35 s).
